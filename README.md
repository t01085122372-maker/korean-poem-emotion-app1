## 3. 감정 범주와 분석 방법

### 감정 범주 8개

| 키 | 이름 | 정의 |
|---|---|---|
| sad | 슬픔 | 상실·이별·죽음 앞에서 마음이 아프고 무너져 내리는 정서. |
| long | 그리움 | 지금 곁에 없는 사람·장소·시간을 다시 만나고 싶어 마음이 그쪽으로 향하는 정서. |
| love | 사랑·헌신 | 대상을 아끼고 그를 위해 자신을 내어 주려는 정서. |
| joy | 기쁨·생동 | 생명력과 즐거움이 차올라 몸과 마음이 들뜨는 정서. |
| calm | 평온·관조 | 감정을 가라앉히고 자연과 세계를 한 걸음 물러서서 담담히 바라보는 정서. |
| will | 의지·저항 | 고난과 억압에 굴하지 않고 앞날을 열어 가려는 굳은 마음. |
| anger | 분노·원망 | 부당한 일이나 받은 상처에 맞서 일어나는 격한 반발과 원망. |
| reflect | 성찰·고뇌 | 자기 자신을 들여다보며 부끄러워하거나 괴로워하는 정서. |

예시 앱의 ‘희망·의지’는 저항시(「그날이 오면」, 「광야」, 「논개」)를 담기 위해 **의지·저항**으로, ‘성찰·부끄러움’은 「거울」의 자아 분열까지 담기 위해 **성찰·고뇌**로, ‘기쁨’은 「봄은 고양이로다」의 생명력을 담기 위해 **기쁨·생동**으로 바꿨습니다.

### 분석 방법 (A. 감정 사전, 브라우저 계산)

1. 본문을 줄바꿈으로 행, 빈 줄로 연을 나눕니다.
2. 각 행에서 감정 사전의 시어를 **긴 것부터** 찾아 감정별로 셉니다(부분 문자열 일치, 어간 사용).
3. 시 전체의 감정별 개수를 합계 1이 되도록 나눠 **사전 비율**을 만듭니다.
4. 반어·역설·상징처럼 사전이 못 읽는 의미를 반영해 작품마다 정해 둔 **해석 프로필**(0–1)도 합계 1로 맞춥니다.
5. **최종 비율 = 사전 비율 × w + 해석 프로필 × (1 − w)** (기본 w = 0.5). 화면 표시는 최대 잔여 방식으로 반올림해 합계를 정확히 100%로 맞춥니다.
6. 지배 정서는 최종 비율이 가장 큰 범주입니다.
7. 추천은 최종 비율 벡터의 코사인 유사도 상위 3편, 감성 지도는 15편 벡터의 주성분분석(공분산 행렬의 고유벡터를 거듭제곱법으로 계산)입니다.

### 감정 사전

범주마다 시어 15~24개(10개 이상 기준 충족). 전체 목록은 `js/data.js`의 `LEXICON`과 웹앱의 ‘분석 방법’ 탭에 있습니다.

예시 앱의 사전을 바탕으로 범주를 바꾸면서 새로 정리했습니다. 주요 변경 내역은 다음과 같습니다.

- **추가:** 신규 8편에 맞춘 시어. 예) 의지·저항 `가련다, 간다, 호미, 앞장, 우렁찬, 뿌려` / 분노·원망 `분노, 들이받, 깨어져, 빼앗, 범하, 쫓겨, 칼, 미친` / 성찰·고뇌 `거울, 근심, 진찰, 외로, 반대, 못알아, 딱한, 골몰, 들여다보, 그림자` / 기쁨·생동 `반갑, 고맙, 가뿐, 뛰놀, 생기, 고운, 좋소` / 평온·관조 `아늑, 흙, 졸음, 포근, 점잖, 조용, 새 노래, 물결` / 그리움 `못 잊, 향수, 돌아다보, 전설, 먼 데` / 사랑·헌신 `입맞추, 아리땁, 정열` / 슬픔 `끊기, 잃었, 초라`
- **삭제:** 오탐이 많은 짧은 시어 `달이, 별을, 별이, 산에, 오는, 피어, 피네`, 범주와 맞지 않는 `무서, 겁, 놀란`
- **이동:** `외로`(슬픔 → 성찰·고뇌), `봄`(희망 → 의지·저항, 검증 사례 3 참고)

## 4. 검증: 계산과 해석이 어긋나는 사례

아래 수치는 웹앱에서 사전만 쓴 결과(w = 100%)와 기본값(w = 50%)입니다.

### 사례 1. 「진달래꽃」 — 반어를 읽지 못함
- **사전 계산:** 분노·원망 43%, 슬픔 29%, 사랑·헌신 28% → 지배 정서 **분노·원망**
- **해석:** 중심은 사랑·헌신과 억눌린 슬픔
- **원인:** ‘나 보기가 역겨워’의 ‘역겨’는 임의 마음을 가정한 말인데 화자의 원망으로 잡히고, 이 구절이 1연과 4연에 반복돼 두 번 세어집니다. ‘죽어도 아니 눈물 흘리오리다’는 슬픔을 부정하는 반어인데 ‘죽어·눈물’이 그대로 슬픔으로 잡힙니다.
- **개선:** ‘아니·않·못’ 같은 부정어가 시어 뒤에 오면 점수를 줄이거나 반어 표시를 하는 규칙, 수미상관으로 반복된 행은 한 번만 세는 옵션. 해석 프로필을 50% 섞으면 사랑·헌신 33%로 1위가 됩니다.

### 사례 2. 「논개」 — 낱말에 끌려가 핵심 정서를 놓침
- **사전 계산:** 사랑·헌신 55%, 평온·관조 36%, 분노·원망 9%, **의지·저항 0%**
- **해석:** 중심은 나라를 위한 희생과 저항 의지
- **원인:** ‘사랑보다도 강하다’에서 사랑은 비교 대상일 뿐인데 사랑으로 잡히고, 후렴의 ‘물결’과 3연의 ‘강물’이 평온으로 잡힙니다. ‘거룩한·죽음을 입맞추었네’처럼 희생을 뜻하는 표현은 사전에 없습니다.
- **개선:** ‘~보다도’ 앞의 비교 대상은 가중치를 낮추는 규칙, 후렴(반복 연)은 한 번만 세기, 희생·순국 시어(`거룩`, `불붙`, `혼`) 추가. 다만 이 시어들은 다른 시에서 오탐을 낼 수 있어 함께 점검해야 합니다.

### 사례 3. 「봄은 고양이로다」 — 범주 배정과 중의성 문제
- **사전 계산:** 의지·저항 34%, 기쁨·생동 25%, 평온·관조 25% → 지배 정서 **의지·저항**
- **해석:** 중심은 봄의 생동감(기쁨·생동)과 나른함(평온)
- **원인:** ‘봄’을 「빼앗긴 들에도 봄은 오는가」, 「모란이 피기까지는」의 희망을 잡으려고 의지·저항에 넣었는데, 이 시에서는 ‘봄’이 네 번 나오며 순수한 계절 감각을 뜻합니다. ‘미친 봄의 불길’의 ‘미친’도 들끓는 생명력의 과장인데 분노로 잡힙니다.
- **개선:** 같은 시어라도 시마다 뜻이 다를 수 있으므로, ‘봄’처럼 중의적인 시어는 범주를 정하지 않고 주변 시어의 감정을 따르게 하거나, 행이나 연 단위 기계학습 분류(방법 B)로 보완합니다.

### 사례 4. 「서시」 — 부분 문자열 오탐
- **사전 계산:** 슬픔 28%, 평온·관조 27%, 의지·저항 18%, 성찰·고뇌 18% → 지배 정서 **슬픔**
- **해석:** 중심은 부끄럼 없는 삶을 향한 성찰
- **원인:** 마지막 행 ‘스치운다’ 속의 ‘운다’가 슬픔으로 잡힙니다(부분 문자열 일치의 오탐). ‘죽는 날까지’, ‘죽어 가는 것’도 슬픔으로 세어지지만, 이 시에서 죽음은 슬픔이 아니라 성찰과 연민의 대상입니다.
- **개선:** 형태소 분석기로 어절을 나눈 뒤 어간 단위로 맞추면 ‘스치운다’의 ‘운다’ 같은 오탐을 막을 수 있습니다. 해석 프로필을 섞으면 성찰·고뇌 27%로 1위가 됩니다.

### 사례 5. 「빼앗긴 들에도 봄은 오는가」 — 표면의 기쁨과 이면의 비애
- **사전 계산:** 기쁨·생동 32%, 의지·저항 24%, 평온·관조 20%, 슬픔 4%
- **해석:** 시 전체를 감싸는 정서는 국토를 빼앗긴 비애와 저항
- **원인:** 가운데 연들의 ‘반갑다, 웃네, 고맙게, 가뿐하다’가 기쁨으로 잡힙니다. 시의 의미를 결정하는 첫 행의 물음과 마지막 행의 탄식은 각각 한 행일 뿐이라 비중이 작습니다. 해석 프로필을 50% 섞어도 기쁨·생동 22%로 1위가 남는, 가장 큰 어긋남입니다.
- **개선:** 첫 행과 마지막 행(수미)에 가중치를 더 주는 규칙, 또는 사전 비율 대신 해석 프로필 비중을 높이는(w를 낮추는) 설정. 슬라이더를 20% 이하로 내리면 슬픔이 1위가 됩니다.

## 5. 한계와 개선 방향

- **부분 문자열 일치의 한계:** 어간을 써서 활용형을 잡는 대신 다른 낱말 속 오탐이 생깁니다(사례 4). 형태소 분석기(예: Kiwi, Mecab)를 쓰는 Python 전처리로 보완할 수 있습니다.
- **문맥과 수사법:** 반어·역설·비교 구문을 읽지 못합니다(사례 1, 2). 부정어·비교어 규칙을 더하거나, KoBERT 같은 모델로 행 단위 감정을 분류해(방법 B) 사전과 함께 쓰는 방향을 생각할 수 있습니다.
- **반복 구조:** 후렴과 수미상관이 같은 시어를 여러 번 세게 만듭니다. 반복된 행을 한 번만 세는 옵션이 필요합니다.
- **해석 프로필의 주관성:** 해석 프로필은 제가 작품을 읽고 정한 값이라 사람마다 다를 수 있습니다. 여러 사람의 평가를 평균 내면 더 믿을 만해집니다.
- **표본 크기:** 15편은 감성 지도(PCA)를 만들기에 적은 수라 축의 의미가 작품 추가에 따라 크게 바뀔 수 있습니다.
