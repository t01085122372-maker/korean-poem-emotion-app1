# 시의 온도 · 한국 근대시 감정 분석 웹앱

한국 근대시 15편의 감정을 **사전 기반**(낱말을 세는 계산)과 **문맥 기반**(시의 흐름·화자·시대배경으로 읽은 정서)으로 나란히 분석하는 정적 웹앱입니다.

## 3. 감정 범주와 분석 방법

### 감정 범주 8개

| 키 | 이름 | 정의 |
|---|---|---|
| sad | 슬픔 | 상실·이별·죽음 앞에서 마음이 아프고 무너져 내리는 정서. |
| long | 그리움 | 지금 곁에 없는 사람·장소·시간을 다시 만나고 싶어 마음이 그쪽으로 향하는 정서. |
| love | 사랑·헌신 | 대상을 아끼고 그를 위해 자신을 내어 주려는 정서. |
| joy | 기쁨·생동 | 생명력과 즐거움이 차올라 몸과 마음이 들뜨는 정서. |
| calm | 평온·관조 | 감정을 가라앉히고 자연과 세계를 한 걸음 물러서서 담담히 바라보는 정서. |
| will | 의지·저항 | 고난과 억압에 굴하지 않고 앞날을 열어 가려는 굳은 마음. |
| anger | 분노·원망 | 부당한 일이나 받은 상처에 맞서 일어나는 격한 반발과 원망. |
| reflect | 성찰·고뇌 | 자기 자신을 들여다보며 부끄러워하거나 괴로워하는 정서. |

예시 앱의 ‘희망·의지’는 저항시(「그날이 오면」, 「광야」, 「논개」)를 담기 위해 **의지·저항**으로, ‘성찰·부끄러움’은 「거울」의 자아 분열까지 담기 위해 **성찰·고뇌**로, ‘기쁨’은 「봄은 고양이로다」의 생명력을 담기 위해 **기쁨·생동**으로 바꿨습니다.

### 분석 방법: 사전 기반 vs 문맥 기반

이 웹앱은 한 편의 시를 두 기준으로 따로 읽고, 둘을 나란히 비교합니다.

| | 사전 기반 | 문맥 기반 |
|---|---|---|
| 무엇을 보나 | 행마다 감정 사전의 **낱말**이 몇 번 나오는지 | ① 시의 **흐름**(수미상관·마지막 연·반전), ② **화자**의 상황, ③ 당대 **시대배경** |
| 어떻게 정하나 | 자동 계산 (방법 A, 브라우저 JavaScript) | 작품마다 정서 강도(0–1)를 정하고 근거를 `context`에 적음 |
| 데이터 필드 | `LEXICON` → `lexVec` | `profile`(기술명세서 3.3) → `ctxVec`, 근거 `context` |
| 강점 | 객관적이고 재현할 수 있음, 근거 시어가 보임 | 반어·역설·상징·시대적 의미를 읽음 |
| 약점 | 문맥·반어·중의성을 못 읽음 | 읽는 사람의 판단이 들어감 |

1. 본문을 줄바꿈으로 행, 빈 줄로 연을 나눕니다.
2. 각 행에서 감정 사전의 시어를 **긴 것부터** 찾아 감정별로 셉니다(부분 문자열 일치, 어간 사용). 이때 다음 세 가지 규칙을 적용합니다.
   - ‘사랑보다도’처럼 **‘~보다’ 앞의 비교 대상**은 세지 않습니다.
   - ‘스치운다’ 속의 ‘운다’처럼 오탐이 확인된 짧은 시어는 **어절 첫머리**에서만 인정합니다.
   - ‘江[강]물’, ‘관(冠)이’ 같은 **한자 병기**는 읽기용 표기이므로 한자를 빼고 한글만으로 시어를 찾습니다.
3. 감정별 개수를 합계 1로 나눈 것이 **사전 기반 비율**입니다(기술명세서 5.3). 과제의 정량 분석은 이 값으로 충족합니다.
4. 문맥 기반 정서 강도를 합계 1로 맞춘 것이 **문맥 기반 비율**입니다.
5. **최종 비율 = 사전 기반 × w + 문맥 기반 × (1 − w)** (기술명세서 5.4, 기본 w = 0.5). 화면 표시는 최대 잔여 방식으로 반올림해 합계를 정확히 100%로 맞춥니다.
6. 두 기준의 **일치도**는 두 비율 벡터의 코사인 유사도이고, 1위 정서가 같은지도 함께 표시합니다. 15편 중 5편은 1위가 같고 10편은 다릅니다.
7. 지배 정서는 최종 비율이 가장 큰 범주입니다. 추천은 최종 비율 벡터의 코사인 유사도 상위 3편, 감성 지도는 15편 벡터의 주성분분석(공분산 행렬의 고유벡터를 거듭제곱법으로 계산)입니다.
8. 직접 입력한 시는 문맥 기반 값이 없으므로 사전 기반 비율만 씁니다.

### 감정 사전

범주마다 시어 15~24개(10개 이상 기준 충족). 전체 목록은 `js/data.js`의 `LEXICON`과 웹앱의 ‘분석 방법’ 탭에 있습니다.

## 4. 검증: 사전 기반과 문맥 기반이 어긋나는 사례

웹앱의 ‘비교 · 감성 지도’ 탭에서 일치도가 낮은 순으로 볼 수 있습니다. 아래 수치는 사전 기반 비율, 문맥 기반 비율, 기본값(w = 50%)의 최종 비율입니다.

### 사례 1. 「논개」 — 비교 대상과 후렴에 끌려감 (일치도 55%)
- **사전 기반:** 사랑·헌신 42%, 평온·관조 33%, 의지·저항 17%
- **문맥 기반:** 의지·저항 37%, 분노·원망 29%
- **최종(w 50%):** 사랑·헌신 28%, 의지·저항 27% → 사전 쪽으로 기움

처음 결과를 보고 좀 의아했다. 이 시는 순국의 의지와 분노가 중심인데, 사랑과 평온이 더 높게 나왔기 때문이다. 이유를 따라가 보니 '정열, 입맞추, 꽃다운' 같은 낱말이 사랑으로 잡혔고, 세 번 반복되는 후렴의 '물결'과 3연의 '강물'이 평온으로 세어지고 있었다. 그래서 '거룩, 불붙'을 사전에 넣었더니 의지·저항이 0%에서 17%로 올랐지만 여전히 부족했다. 후렴을 한 번만 세는 방법도 시험해 봤다. 이 시에서는 나아졌지만 「향수」의 그리움이 42%에서 22%로 떨어져서, 모든 시에 적용하지는 않았다. 한편 w를 45% 이하로 낮추면 의지·저항이 1위가 되는 것은 확인했다.

### 사례 2. 「빼앗긴 들에도 봄은 오는가」 — 표면의 기쁨과 이면의 비애 (일치도 61%)
- **사전 기반:** 기쁨·생동 32%, 의지·저항 24%, 평온·관조 20%
- **문맥 기반:** 슬픔 26%, 의지·저항 23%
- **최종(w 50%):** 의지·저항 24%, 기쁨·생동 20%

기쁨이 1위로 나온 것은 가운데 연의 '반갑다, 웃네, 고맙게' 때문이었다. 그런데 이 시에서 그 기쁨은 꿈속의 착각이고, 시는 '봄조차 빼앗기겠네'라는 탄식으로 끝난다. 정작 중요한 첫 행과 마지막 행은 한 줄씩뿐이라, 낱말 수를 세는 사전 방식에서는 비중이 작을 수밖에 없다. 첫 행과 마지막 연에 가중치를 더 주면 의지와 분노가 올라갈 것이라고 본다. 문맥 기반으로는 슬픔이 1위였고, 최종 결과에서도 슬픔이 1위가 되려면 w를 10% 이하로 낮춰야 했다.

### 사례 3. 「떠나가는 배」 — 떠남의 결심과 미련 (일치도 71%)
- **사전 기반:** 의지·저항 31%, 평온·관조 23%, 슬픔 15%
- **문맥 기반:** 슬픔 31%, 그리움 29%
- **최종(w 50%):** 의지·저항 24%, 슬픔 23%

의지가 1위로 나온 것은 1연과 4연에 반복되는 '간다, 가련다'가 네 번 세어졌기 때문이다. 그런데 이 시는 단호함보다 미련에 가깝다. '나 두 야'처럼 띄어 쓴 표현은 망설임이고, 가운데 연은 두고 가는 사람들 이야기다. '아늑한, 구름, 바람'도 평온이 아니라 떠나기 아쉬운 풍경으로 읽어야 한다. 반복되는 행을 한 번만 세거나 풍경 낱말을 사전에서 빼면 고쳐질 것 같다. w를 45% 이하로 낮췄을 때는 슬픔이 1위가 됐다.

### 사례 4. 「봄은 고양이로다」 — 중의적 낱말과 범주 배정 (일치도 72%)
- **사전 기반:** 의지·저항 33%, 기쁨·생동 25%, 평온·관조 25%
- **문맥 기반:** 기쁨·생동 51%, 평온·관조 40%

'봄'을 의지·저항에 넣은 것은 다른 시의 희망 표현을 잡으려는 것이었는데, 이 시에서 '봄'은 그냥 계절이다. '미친 봄의 불길'의 '미친'도 생명력을 강조한 말인데 분노로 세어졌다. 같은 낱말이 시마다 다른 뜻으로 쓰이니 사전만으로는 한계가 있다. 같은 행의 다른 시어를 보고 감정을 정하는 규칙이나, 행 단위로 감정을 분류하는 기계학습(방법 B)으로 보완할 수 있을 것이다.

### 사례 5. 「진달래꽃」 — 반어를 읽지 못함 (일치도 79%)
- **사전 기반:** 분노·원망 43%, 슬픔 29%, 사랑·헌신 28%
- **문맥 기반:** 슬픔 38%, 사랑·헌신 37%

'나 보기가 역겨워'가 두 번 나와서 원망이 두 번 잡혔고, '즈려밟고'도 원망으로 잡혔다. 더 큰 문제는 '죽어도 아니 눈물 흘리우리다'였다. 울지 않겠다는 말이 오히려 슬픔을 드러내는 반어인데, 사전은 이를 구분하지 못한다. '아니, 않, 못' 같은 부정어 규칙을 시험해 봤더니 '눈물'까지 같이 빠져서 슬픔이 0%가 됐다.

### 사전 규칙으로 고쳐진 사례
- 「서시」: ‘스치운다’의 ‘운다’가 슬픔으로 잡히던 오탐을 규칙 2로 없앴습니다. 사전 기반 1위가 슬픔(28%)에서 평온·관조(30%)로 바뀌고 슬픔은 20%로 줄었습니다. ‘하늘·바람’이 평온으로 잡히는 문제는 남아 있습니다.
- 「논개」: ‘사랑보다도’의 ‘사랑’이 규칙 1로 빠졌습니다.

## 5. 한계와 개선 방향

- **부분 문자열 일치의 한계:** 어간을 써서 활용형을 잡는 대신 다른 낱말 속 오탐이 생깁니다(사례 4). 형태소 분석기(예: Kiwi, Mecab)를 쓰는 Python 전처리로 보완할 수 있습니다.
- **문맥과 수사법:** 반어·역설·비교 구문을 읽지 못합니다(사례 1, 2, 5). 부정어·비교어 규칙을 더하거나, KoBERT 같은 모델로 행 단위 감정을 분류해(방법 B) 사전과 함께 쓰는 방향을 생각할 수 있습니다.
- **반복 구조:** 후렴과 수미상관이 같은 시어를 여러 번 세게 만듭니다. 반복된 행을 한 번만 세는 옵션이 필요합니다.
- **문맥 기반의 주관성:** 문맥 기반 강도는 제가 흐름·화자·시대배경을 근거로 정한 값이라 사람마다 다를 수 있습니다. 근거를 `context`에 적어 검토할 수 있게 했고, 여러 사람의 평가를 평균 내면 더 믿을 만해집니다.
- **규칙의 부작용:** 한 시를 고치는 규칙이 다른 시를 망칠 수 있습니다(부정어 규칙 → 「진달래꽃」, 반복 행 규칙 → 「향수」). 그래서 15편 전체에서 나빠지는 시가 없는 규칙만 넣었습니다.
- **표본 크기:** 15편은 감성 지도(PCA)를 만들기에 적은 수라 축의 의미가 작품 추가에 따라 크게 바뀔 수 있습니다.
